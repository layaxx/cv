# My personal CV (English & German)

This repository contains a personal CV written in LaTeX with English and German variants.

- `cv-english.tex` — English CV source
- `cv-german.tex` — German CV source

Based on a template by Omar Roldan: <https://www.overleaf.com/latex/templates/cv-developer/rdycxzvvnvcc>

## PDF Version

Rendered PDF files can be found on the [Releases page of this repository](https://github.com/layaxx/cv/releases).
